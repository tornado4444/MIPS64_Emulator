# MIPS64 Emulator

An attempt to implement the legendary MIPS64 emulator.

# SUPPORTED PLATFORMS

|         Platform    |    Compiler   |       Architecture   |
| ------------------  | ------------- | -------------------- |
| Windows 10          | MSVC+CL       | x86+x64, ARM/ARM64   |
| Linux               | Clang+GCC     | x86_64, aarch64      |
| Android             | NDK CLANG     | x86, x86_64, arm64-v8a, arm7a |
